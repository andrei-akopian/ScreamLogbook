# Common LISP

## Compilers

[Steel Bank Common Lisp](https://www.sbcl.org/)

Alias with `rlwrap` (readline) for marginally better repl experience.

```bash
# .bashrc or .zshrc alias
# Steel Bank Common Lisp
alias sbcl="rlwrap sbcl"
```
